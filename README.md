# 🍳 레시피 노트 (Recipe Note)

CJ 크레잇 카탈로그 형태의 **메뉴 레시피 노트 웹앱**입니다.
빌드 도구 없이 순수 HTML/CSS/JS로 되어 있어 **폴더만 올리면 배포**됩니다.

- **뷰어** (`index.html`) — 카테고리별 메뉴 카드 → 클릭하면 재료·조리법·사용제품 상세
- **관리자** (`admin.html`) — 폼으로 레시피 추가/수정, 사진 업로드, 카테고리·사이트 설정
- **데이터** (`data/recipes.json`) — 레시피와 이미지가 **이 파일 하나에** 저장됩니다 (이미지는 자동 압축되어 파일 안에 포함)

---

## 📁 폴더 구조

```
recipe-app/
├─ index.html          뷰어(공유용 메인 페이지)
├─ admin.html          관리자 편집 화면
├─ data/recipes.json   레시피 데이터 (+ 이미지 포함)
├─ css/                스타일
├─ js/                 로직
├─ server.js           로컬 미리보기용 서버
└─ README.md
```

---

## ▶️ 로컬에서 실행하기 (미리보기 + 편집)

`index.html`을 파일로 바로 열면 데이터 로딩이 제한되므로, **간단한 서버로 실행**하세요.

```bash
node server.js
```

그런 다음 브라우저에서:

- 뷰어: **http://localhost:5173**
- 관리자: **http://localhost:5173/admin.html**

> Node.js가 설치되어 있으면 별도 설치 없이 바로 됩니다.

---

## ✍️ 레시피 추가하는 법

1. `admin.html` 열기
2. **+ 새 레시피** → 메뉴 이름, 카테고리, 재료, 조리법, 사진 등 입력
3. **저장 (Ctrl+S)** → 편집 내용이 브라우저에 임시 저장됩니다
4. 다 됐으면 우측 상단 **💾 내보내기(배포)** 클릭 → `recipes.json` 파일이 다운로드됩니다
5. 다운로드된 `recipes.json`을 이 프로젝트의 **`data/` 폴더에 덮어쓰기**
6. (배포했다면) 커밋/업로드하면 공유 사이트에 반영됩니다

- **사이트 제목·부제목·카테고리**는 관리자 상단 **🏷️ 사이트·카테고리**에서 수정
- 다른 PC에서 이어서 작업하려면 **📥 가져오기**로 기존 `recipes.json`을 불러오세요
- **↺ 초기화**는 브라우저 임시 저장분만 지웁니다 (내보낸 파일은 안전)

> ⚠️ 편집 내용은 **내보내기 → data/recipes.json 교체**를 해야 실제로 배포·공유됩니다.
> 브라우저 임시 저장만으로는 다른 사람에게 보이지 않습니다.

## 🔒 관리자 비밀번호 잠금

관리자 화면을 비밀번호로 잠글 수 있습니다.

1. `admin.html` → **🏷️ 사이트·카테고리** → **🔒 관리자 비밀번호**에 원하는 비밀번호 입력 → **비밀번호 적용**
2. **💾 내보내기 → `data/recipes.json` 교체 → 배포** (이 단계를 해야 실제 사이트에 잠금이 반영됩니다)

이후 관리자 화면에 들어오면 비밀번호를 입력해야 편집 폼이 열립니다.
- 비밀번호를 **비운 채로 적용**하면 잠금이 해제됩니다.
- 비밀번호는 평문이 아니라 **SHA-256 해시**로 저장됩니다.

> ⚠️ 이 잠금은 **캐주얼한 접근 차단용**입니다. 정적 사이트라 데이터 파일은 공개되어 있어, 마음먹고 우회하는 것까지 막지는 못합니다(단, 우회해도 **남의 공유 사이트를 바꿀 수는 없습니다** — 편집은 각자 브라우저 안에서만 유효). 추측하기 어려운 비밀번호를 쓰세요.

## 🚀 GitHub Pages로 배포하기

### 1) GitHub 저장소 만들기
- github.com 에서 새 저장소 생성 (예: `recipe-note`)

### 2) 이 폴더를 업로드
```bash
cd recipe-app
git init
git add .
git commit -m "레시피 노트 첫 배포"
git branch -M main
git remote add origin https://github.com/<사용자명>/recipe-note.git
git push -u origin main
```
> Git이 없다면 GitHub 저장소 페이지에서 **Add file → Upload files**로 폴더 내용을 드래그해 올려도 됩니다.

### 3) Pages 켜기
- 저장소 → **Settings → Pages**
- **Source: Deploy from a branch**, **Branch: `main` / `(root)`** 선택 후 Save
- 1~2분 뒤 **`https://<사용자명>.github.io/recipe-note/`** 주소가 생성됩니다 → 이 링크를 공유하세요

### 이후 업데이트
레시피를 추가했다면 → 관리자에서 **내보내기** → `data/recipes.json` 교체 → 다시 커밋/업로드하면 사이트가 갱신됩니다.
